# Meme angle taxonomy

Use these as search directions, not quotas. One story can support several mechanisms.

| Mechanism | Comic relationship | Typical catalog meanings |
|---|---|---|
| contradiction | A claim and the observable reality cannot both stand comfortably | expectation versus reality, literal correction, reveal |
| reversal | Reassurance or progress is overturned by the next fact | alarm, calm, worse alarm; plan, failure, realization |
| hidden constraint | Impressive capability is bottlenecked by a mundane boundary | grand capability versus tiny constraint; supposedly simple task |
| misclassification | An institution confidently calls a thing by the wrong name | mistaken question, misused word, surface identity unmasked |
| false shortcut | A clever-looking workaround defeats the actual goal | flawed logic, tempting trap, intended path abandoned |
| scale mismatch | A tiny input causes a huge burden, or a large effort produces a tiny result | undersized effort, proliferation, instant loss |
| preference contrast | The same actor rejects one comparable option and chooses another | reject/prefer, two options and an ideal third |
| false choice | Two options presented as exclusive can coexist | choose both, shared trait, mirrored actors |
| ownership mismatch | Credit, responsibility, or control lands with the wrong actor | stolen credit, sudden control, silenced truth |
| recursive absurdity | The proposed solution contains another copy of the same problem | nested activity, moving the problem, repeated pattern everywhere |
| reluctant update | New evidence changes an initial reaction | dislike then approval, perspective shift, suspicious ambiguity |
| institutional memory | A once-normal practice has been forgotten or made strange | remembers, unfamiliar familiar thing, delayed admission |

An angle is stronger when the source supplies both sides of the relationship. “Company uses AI” has
no comic payload. “The company installed 450 sensors, then created 32 weeks of review work per day”
has a capability-versus-constraint payload.

Avoid angles whose entire joke is that AI is bad, executives are stupid, workers are replaceable, or
a named person looks foolish. Those are attitudes, not mechanisms.
