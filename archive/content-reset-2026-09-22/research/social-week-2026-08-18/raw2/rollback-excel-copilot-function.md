# Microsoft kills the Excel COPILOT() function five weeks' notice, "decided not to move forward"

- URL: https://www.theregister.com/ai-and-ml/2026/08/17/excels-copilot-function-is-headed-for-the-recycle-bin/5288327
- Publication: The Register
- Date published: 2026-08-17 (Monday)
- Date accessed: 2026-08-18
- Headline: "Excel's Copilot function is headed for the Recycle Bin"
- Subhead: "Microsoft realizes the side pane should be enough for anyone"

## Verbatim extract

What is being removed: Excel's COPILOT() function, which allowed users to send instructions
to Microsoft's AI assistant directly from worksheet cells.

Removal date: September 14, 2026.

Microsoft 365 roadmap statement (CONFIRMED, MICROSOFT'S OWN WORDS):
"We have decided not to move forward with this feature. We apologize for the inconvenience."

"this change helps streamline the Copilot experience within Excel while continuing to provide
AI assistance through a supported interface."

"Customers can continue using Copilot in Excel through the Copilot side pane, which provides
many of the same AI-powered capabilities, including summarizing text, classifying data,
generating content, and retrieving information from the web."

Context: the function debuted in August 2025 for preview users with Microsoft 365 Copilot
licenses and was initially planned for general availability in 2027. It remained in preview
status, so users were not supposed to rely on it for production workflows.

## Analyst notes
- CONFIRMED: everything above is Microsoft's published roadmap language plus dates.
- INFERRED (by The Register, not Microsoft): that the side pane's sufficiency is the real
  reason. Microsoft gives no cost or quality rationale.
- Caveat to state plainly: the feature was in PREVIEW, never GA. That materially lowers the
  "vendor yanked a production feature" reading. Anyone who put COPILOT() into a live workbook
  did so against Microsoft's own preview terms — which is exactly the executive lesson.
