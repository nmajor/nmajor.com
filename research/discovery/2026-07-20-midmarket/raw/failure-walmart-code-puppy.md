--- Bloomberg (2026-06-01) ---
"Walmart Inc. is limiting staff's usage of an artificial-intelligence tool following high demand,
illustrating how corporations are adjusting their calculations for incorporating the technology.
The retailer is now offering a set amount of 'tokens' per employee to use Code Puppy, an AI agent
that helps with tasks ranging from spreadsheets to presentations, said people familiar with the
matter who declined to be named discussing private information. Before, staff had an unlimited
amount of tokens — the unit of data for AI computing."

--- Business Insider ---
"Walmart's new internal vibe coding tool is getting popular. A little too popular."
Walmart CTO Suresh Kumar: Code Puppy is now used by about as many non-engineers as engineers,
"all the way to hourly associates."
Kumar: "If five associates or 100 associates are asking almost similar things, then it's an
opportunity for us to elevate that capability at an enterprise level; we've got a different vibe
coding platform that our engineers use."
CEO John Furner: "We just simply surface what's already been built, and then we see the adoption
rates go much faster."
A Walmart employee using the tool told BI he had yet to hit the token limit, which resets after a
period, "though he knows colleagues who have."
Walmart's framing: the cap is about cutting DUPLICATIVE vibe coding — many associates independently
building the same thing.

--- PYMNTS (2026-06-01) ---
"Sources familiar with the matter told Bloomberg that Walmart has begun offering a set number of
tokens ... each employee can use with its in-house AI agent Code Puppy. Before this, workers had an
unlimited number of tokens."
A Walmart spokesperson told Bloomberg the company wants employees to apply AI to create value, and
that it is "guiding workers to use the right AI for the right task."

--- artificialintelligence-news.com ---
Notes 'token maxxing' — employees gamifying AI-usage KPIs; internal AI leaderboards. Sequoia partner
told WSJ (April 2026) "We all should be tokenmaxxing".

NOTE: this is a cost-overrun / rationing story on a tool Walmart BUILT ITSELF (full cost visibility)
— not a vendor surprise. Walmart is ~2.1m employees: far outside mid-market, but the mechanism
(unmetered internal AI tool, adoption outruns budget, duplicated builds nobody knew existed) is the
mid-market pattern at scale. NOT a full abandonment.
