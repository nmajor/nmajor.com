# RAW — Ask HN: Do you know of any company that went back to hand-written code?
Accessed: 2026-08-18. Lane: Hacker News (Algolia, points>40, last 30 days).
URL: https://news.ycombinator.com/item?id=49318906 — posted 2026-08-16 — 105 points, 121 comments

## Thread summary
Question: has any company reversed course from LLM code generation back to manually written code?
Key finding: NO concrete company examples surfaced. Commenters raised Ford, IBM, Commonwealth Bank; each was pushed back on in-thread — those companies rehired people to IMPROVE their AI systems, not to abandon them.

## Comments (verbatim excerpts + usernames)
- jaccola (startup, 15 engineers): "having derived the code and built a mental model is something like 90% of the work, the code artefact being 10%". Uses Claude only on "commoditised pieces" like account UI, not core tech.
- gamerDude (startup founder): "managing developers with AI has become very difficult to get them to slow down and build stable". Considered reverting after prototyping created unmanageable technical debt; team acknowledged AI enabled the mess but resisted dropping it; still deciding.
- i2km (startup in a deep technical area): "We are basically no technical debt, we can fix issues rapidly and we can stand behind our codebase". Never adopted AI for development, only for code review; says clients would treat AI-generated code as disqualifying.
- rpdillon: "It's a giant red flag... that's an issue of the developers' judgment not being any good, not a problem with AI".
- quantumwoke: his wife, a physician, abandoned AI scribes because verification work eroded the productivity gain.
